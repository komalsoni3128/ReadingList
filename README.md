# ReadingList App

A web application for keeping track of books and monitoring reading progress.

## Features

* Add and manage books in your reading list.
* Track the number of books read.
* Organize your reading list in one place.

## Purpose

The ReadingList App helps users maintain a record of their reading activity and keep track of their books.
